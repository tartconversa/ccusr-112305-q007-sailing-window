# 资料口径

历史 planned/actual 为从工序应开始计的天数，空 actual 代表截至可见周未知，重复 lot 不表示不同成品。当前运单以其排运日零时后的小时计，预计就绪不等于通过。pieces 是分包实物件数，整套按所有规定分包都能随同一航班装齐计算；可拆单 min_gap_h 为两批发船时点之间的最短间隔。
舱位 cap_pieces 以装进该箱型的实际件数计。箱型与目的港绑定，同港可合箱。cancel_h 是取消免等待或换舱接受前的最后时点，超过后仍可能由货代接受但需计费，cut_h 后不能新装。装车标志表示已装不可自行撤回，需以货代解除或拒绝回执为据。预订接受才正式占舱，收到撤改单不代表替代已生效。

load_events 的箱号是实物箱唯一标识。码头实装是判断实际运输的事实，入柜和重复报送均不等于离港。pieces 是独立装入的零件实数。客户响应可以有部分接受和后续欠件约定，接受的已交成套数有效，不能视作余量免付或逾期责任免除。dock_costs 中 actual 指已发生，不和预测补发成本相抵。
